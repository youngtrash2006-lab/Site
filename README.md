# Проект самостоятельной работы (СРО): Облачный деплой и безопасность веб-приложения

Данный репозиторий содержит исходный код статического веб-ресурса, развернутого в глобальной облачной инфраструктуре с использованием принципов CI/CD (автоматической непрерывной поставки).

##  Краткая информация о проекте
* **Назначение:** Публикация статического веб-сайта в облачном сервисе AWS Amplify Hosting с привязкой к системе контроля версий.
* **Технологический стек:** Чистый HTML5, CSS3, JavaScript без сторонних библиотек.
* **Схема деплоя:** Автоматическая сборка и публикация при каждом изменении (коммите) в основной ветке `main`.
* **Доступность:** Проект защищен протоколом HTTPS и обслуживается через глобальную сеть доставки контента (CDN).

---

##  Архитектура и этапы реализации

1. **Управление версиями (GitHub):**
   * Исходный код приложения аккуратно упакован в единственный файл разметки `index.html`.
   * В качестве рабочей среды используется ветка `main`, выступающая источником данных для облачного сервера.

2. **Облачная публикация (AWS Amplify):**
   * Произведена интеграция репозитория GitHub с сервисом AWS Amplify через официальное приложение аутентификации.
   * Поскольку проект не требует предварительной компиляции (транспайляции или сборки скриптов), параметры сборки оставлены дефолтными, а файлы напрямую транслируются в сеть.
   * Настроен автоматический конвейер: изменения проходят стадии инициализации, развертывания и верификации за считанные минуты.

##  Анализ и оценка киберрисков

Ввиду того, что архитектура проекта базируется исключительно на статическом контенте (отсутствуют серверный код, базы данных и интерактивные формы ввода пользовательских данных), классические серверные уязвимости (например, инъекции или несанкционированный доступ к ОС) здесь минимизированы. Основные векторы угроз сосредоточены в области инфраструктуры и цепочки поставок кода:

| Вектор угрозы | Уровень риска | Потенциальные последствия | Рекомендуемые контрмеры |
| :--- | :--- | :--- | :--- |
| **Компрометация учетных записей** | Высокий | Внедрение вредоносного кода и его мгновенная трансляция пользователям | Использование двухфакторной аутентификации (2FA), защита ветки `main` от прямых правок |
| **Непроверенные коммиты** | Средний | Появление уязвимостей или нежелательного функционала на продакшене | Внедрение строгих правил код-ревью перед слиянием ветки |
| **Сетевые атаки (DDoS)** | Средний | Временная недоступность ресурса | Использование встроенных механизмов кеширования CloudFront и AWS Shield |
| **Отсутствие заголовков безопасности** | Низкий | Риски атак типа Clickjacking или перехвата контента | Настройка HTTP-заголовков (`CSP`, `X-Frame-Options`, `X-Content-Type-Options`) на стороне Amplify |
